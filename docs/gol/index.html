Nasıl okunur? Gerçekleşen %: o aralıktaki maçların yüzde kaçının o sonuçla bittiği. Oranın beklediği %: oranın kendi içinde ima ettiği olasılık (1 / oran). Yeşil fark: sonuç orandan daha sık çıkmış, kırmızı fark: daha az çıkmış. Renkler genel ortalamaya göredir: yeşil = ortalamanın üstü, sarı = ortalama, kırmızı = altı. Az maçlı (< 20) satırlar soluk gösterilir, güvenilir değildir. Geçmiş sonuçlar geleceği garanti etmez.
